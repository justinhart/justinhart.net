# justinhart.net

| Item | Use |
| --- | --- |
| Build | `npm run build`; Eleventy generates `docs/` for GitHub Pages. |
| Publications | Edit [`src/_data/publications.bib`](src/_data/publications.bib). Each record also gets a downloadable BibTeX file. |
| Videos | Edit [`src/_data/videos.json`](src/_data/videos.json): title, description, date, section, URL, and verified embed identifier. |
| Paper links | A video's `paperKeys` match BibTeX keys. Use `Talk video` for presentations, `Demo video` for demonstrations, and `Film` for documentaries. |
| Media mentions | Edit [`src/_data/mentions.json`](src/_data/mentions.json). Keep outlet, date, title, description, and source link separate. |
| Order | Newest first within sections. Talk event dates take precedence when known; upload dates are labeled. Undated coverage comes last. The team-video section stays at the bottom. |
| Embeds | Lazy YouTube privacy-enhanced players and Vimeo players, with direct viewing links. Videos remain on their original hosts. |
| Windows preview | The local start/stop/build launchers are in the parent folder; preview output and runtime files stay outside this repository. |
| Update, September 30, 2026 | Added two accepted papers from the current CV, 35 videos, and 43 coverage entries. No submitted or rejected manuscript records were imported. |
| Lab inventory | All four public uploads from [LivingWithRobotsLab](https://www.youtube.com/@LivingWithRobotsLab/videos), checked September 30, 2026. |
| Team archive | [Official year pages](https://www.cs.utexas.edu/~AustinVilla/athome/) plus uploader metadata. The 2025 page reuses the 2024 video; it is listed once. |
| Historical links | Four unavailable original pages use labeled Internet Archive searches. The New Scientist entry links to its publisher's issue archive; the film links to the original distributor on Vimeo. |
| Local checks | Build, internal links and publication anchors, BibTeX downloads, sorting, embed metadata, private-record exclusion, and six preview routes checked. |
